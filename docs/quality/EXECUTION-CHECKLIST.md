## 8. 停止与回滚触发条件

出现以下任一情况，立即停止并回滚：

1. 换钥后出现无法解释的全站 401，或服务起不来。
2. 迁移任一脚本失败，或对账断言出现非 0 行。
3. 备份恢复演练行数不一致。
4. 死信演练触发真实业务消息丢失。
5. 支付回调改造后出现重复开课或丢单。
6. HTTPS 改造后 SSE 不能流式输出或支付回调不可达。

回滚后记录：触发条件、影响范围、回滚步骤、后续任务 ID。
