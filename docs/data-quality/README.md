# 数据质量评估实践（独立）

> 本目录是**独立的数据质量实践**，使用公开数据集，不依赖本仓库代码、业务数据或运行环境；与本仓库的测试报告互不引用。

- 数据：Olist 巴西电商公开数据集，8 张关联表、550,759 行（CC BY-NC-SA 4.0，禁止商业使用）
- 方法：完整性 / 一致性 / 唯一性 / 准确性 / 及时性 / 有效性 六维、32 条 SQL 规则
- 结论：可评分五维综合 99.12（权重自设，不代表行业基准），质量分级 Bronze
- 入口：[REPORT.md](./REPORT.md)（含口径声明、问题清单、根因、SLA 与元数据字段、复现方式）

## 目录

| 路径 | 内容 |
|---|---|
| `REPORT.md` | 评估报告（全部数字可回溯到 `result/`） |
| `sql/` | 按维度拆分的 7 个 SQL 文件，共 32 条规则 |
| `result/` | 规则执行输出（聚合结果，不含原始数据） |
| `run_dq.py` | 执行器：CSV → DuckDB → 按文件名顺序跑 SQL → 汇总评分 |

## 复现

```bash
# 1) 将 8 个 Olist CSV 放入 data/（文件名见 REPORT.md §10.3）
# 2) 运行
python run_dq.py
```

`data/` 与 `olist.duckdb` 不入库（见 `.gitignore`）：原始数据受 CC BY-NC-SA 4.0 约束，本目录只保存分析产物。

## 边界

- 准确性仅覆盖规则可判定部分，未与权威主数据比对，**不代表真实准确率**。
- 及时性因原始数据无入库时间戳不评分；综合分在其余五维上按 90% 归一化。
- 未做修复后重跑，故不声明任何「违规率下降」结论。
